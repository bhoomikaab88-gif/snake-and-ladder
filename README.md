🐍 Snake and Ladder Game
📌 Project Description

Snake and Ladder is a classic board game developed using HTML, CSS, and JavaScript. The game allows players to roll a dice, move across the board, climb ladders, and slide down snakes to reach the final position.

The main objective is to reach square 100 before the opponent.

🎮 Features
Interactive Snake and Ladder game board.
Dice rolling functionality.
Player movement based on dice results.
Ladders help players move forward.
Snakes move players backward.
Simple and user-friendly interface.
Winning condition when a player reaches the final square.
🛠️ Technologies Used
HTML – Structure of the game.
CSS – Styling and board design.
JavaScript – Game logic, dice rolling, and player movement.
🚀 How to Run the Game
Download the project HTML file.
Locate the snake and ladder.html file on your computer.
Double-click the HTML file.
The game will open in your default web browser.
Roll the dice and start playing!
